What this site is

A chapter-based, hands-on path to designing GraphQL APIs well, built around a single GraphQL schema in SDL — diffed for breaking changes by graphql-inspector — for a shipping and cargo domain. GraphQL here is the read-oriented tracking view: one query-shaped graph that stitches cargo, route legs, and handling events together, so a client asks for exactly the fields it needs in a single round trip. Every hands-on chapter ships the same example in both Quarkus (SmallRye GraphQL) and Python (Strawberry). Both are code-first: CI diffs each service's exported schema against the canonical SDL and asserts every response against it, so a 200 that carries a result that does not match the schema fails the build. You work through schema design, queries and mutations, resolvers and the N+1 problem with dataloaders, pagination, error handling, schema evolution, query cost limits, persisted queries and caching, security, observability, federation, subscriptions, testing and debugging, and running the service on Kubernetes. It assumes you can read Java and Python; it is not a tutorial in either language. The code tabs are built to admit more stacks later. All container images are UBI-based, and the stack runs on Docker Compose and minikube.
